# React Bits (сторонній код)

Файли в цій папці взяті з reactbits.dev, варіант TypeScript + CSS. Єдина правка описана
нижче в розділі «Локальні патчі».
Кастомізація робиться пропсами, CSS-override і обгортками зовні, не правками тут.

| Компонент | Джерело | Залежності |
|---|---|---|
| `CircularCarousel.tsx` + `.css` | https://reactbits.dev/r/CircularCarousel-TS-CSS.json | немає |
| `ElectricLogo.tsx` + `.css` | https://reactbits.dev/r/ElectricLogo-TS-CSS.json | `ogl` |

Взято 2026-10-13. Щоб оновити: завантажити JSON за посиланням і замінити файли вмістом
поля `files[].content`. CLI `shadcn add` не використовується: він вимагає `components.json`
і ініціалізації проєкту.

## Локальні патчі

Після оновлення файлів з реєстру ці правки треба внести знову.

| Файл | Що змінено | Навіщо |
|---|---|---|
| `ElectricLogo.tsx` | У циклі кадру `progress + dt / 1.4` замінено на `progress + dt / 0.65` (рядок позначено коментарем `KINDRATYAK patch`) | Розряди проявлялися за 1.4 с, а все інтро триває 2.8 с. Пропсом ця тривалість не керується |
